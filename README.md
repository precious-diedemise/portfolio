# Precious Diedemise — portfolio website

A static website suitable for GitHub Pages.

## Files
- `index.html` — the page content
- `style.css` — colors, fonts, layout, and mobile styling
- `script.js` — clickable project and blog previews
- `Diedemise_Precious_Resume.pdf` — downloadable résumé

## Publish an update
Upload these four files into the **root** of your existing GitHub `portfolio` repository and commit the changes. GitHub Pages will automatically update your live website at preciousdiedemise.me.

Do not upload the ZIP itself. Extract it and upload its files.

## Editing later
- Edit the page wording, featured cards, and contact information in `index.html`.
- Adjust the design in `style.css`.
- Edit the project preview text in `script.js`.
- Replace the PDF with the latest résumé, using the same filename to preserve links.

The current project and blog previews are placeholders, not finished case studies or published essays.
